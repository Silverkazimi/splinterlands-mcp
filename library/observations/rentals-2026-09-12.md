# Public delegation rental observations — 2026-09-12

Sources: official VAPI specification https://vapi.splinterlands.com/swagger/swagger-ui-init.js and anonymous bounded GET requests to https://vapi.splinterlands.com. No account selector or credential was transmitted.

| Route | Captured result |
| --- | --- |
| /delegation-rental/v3/offers | SPSP offer rows with string quantities and pricePerToken, numeric status and expirationBlocks. |
| /delegation-rental/v3/bids | SPSP bid rows with string quantities, pricePerToken and escrow; currency DEC. |
| /delegation-rental/v3/offers/lowest-price | data.price string 0.002. |
| /delegation-rental/v3/bids/lowest-price | data.price string 0.001. |

The names describe delegation-market data. These tools do not find cards to rent as Land workers. Prices and quantities are not converted, annualized or inferred to be executable quotes.

## Measured filters

For both V3 lists, limit=2&offset=0 plus limit=2&offset=2 matched the transaction IDs from limit=4&offset=0 exactly. This is evidence of paging, not snapshot isolation across calls.

minQuantity=10000 returned quantities at least 10000; maxQuantity=1000 returned quantities at most 1000; minQuantity=maxQuantity=10000 returned exactly that quantity. The measured comparison uses qtyAvailable, not an inferred total.

minPrice=1 returned an empty success list; maxPrice=1 returned populated rows. Both minPrice=0.001 and maxPrice=0.001 returned HTTP 400 with a numeric-string validation message, despite the specification declaring number inputs. The tool forwards supplied values unchanged and surfaces these failures. No hidden price scaling is asserted. Player filtering, sort/order effectiveness and other untested values remain unmeasured.

An explicit integer limit in [1,100] and a nonnegative integer offset are tool policy. The V3 specification declares numeric parameters without those bounds; no upstream maximum was measured. Local response projection still limits data to 100 complete rows / 256 KiB, reports truncation and does not fetch continuation pages.

## Response integrity

Original status/data envelopes are retained. Every returned row must satisfy the captured common fields, including rows after the first. Empty arrays are accepted; missing/null data is not silently interpreted as an empty market. Lowest-price null is allowed by the official schema (not seen in these populated captures); missing data or price is malformed.

Fixtures preserve complete bounded responses. The token field contains the public asset symbol SPSP, not a credential. Player names in the actual public responses are fixture data only and were not sent as selectors or made source defaults.

## Remaining routes

The legacy /delegation-rental/bids route had two 20-second read timeouts, with limit=2&offset=0 and limit=1. No usable response body was captured. It is excluded on that dated evidence; authentication and response shape are unknown, and V3 is not a silent redirect.

Pending-player offers, player-specific V3 offers/bids, legacy rentals by player/bid, and V3 rentals by player/role still require route-specific evidence. Public market list success does not prove their selectors, auth behavior or contracts.

Retained evidence: rentals-probes-2026-09-12.json summarizes all 24 anonymous probes, including failures. rentals-live-2026-09-12.json records seven successful calls through the built stdio MCP, including bounded list pages, both prices, exact quantity ranges and an empty price-filter result.


## Legacy bid lookup — 2026-09-13

The public bid transaction identifier returned by a player rental lookup was used in one bounded GET to /delegation-rental/rentals/bid/{bid}, with limit=3 and offset=0. The populated response matched the player-route record, preserving participant names, transaction identifiers and string quantity/payment/price fields. The rentals_by_bid tool and rentals-bid.fixture.json retain that contract. A fresh built-stdio call returned the same populated record. This one-row observation does not prove paging or ordering behavior, and no V3 contract is inferred from the legacy route.
