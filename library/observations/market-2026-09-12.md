## Measured selector limits

Active rentals without owner, renter or card_detail_id returned HTTP 400 naming those alternatives. All three were individually tested; owner and card scopes returned records, renter returned an empty array. With card_detail_id=1, limit=1 returned one row and limit=2 returned two. offset=2 and take=2 with skip=2 repeated the exact same two row IDs. These two declared offsets remain forwardable, but are marked inert and are not working pagination.

By-card id=1 and card_detail_id=1 selected the same leading sale listing. Grouped card_ids=1,2 and limit=1 returned two groups with one listing per group. Rental queries for card 1 returned empty until rental_type=season was added to type=rent. Uppercase RENT alone also returned empty; no general enum equivalence is claimed.

Rental history player and username aliases returned the same two rows with limit=2 or take=2. limit=1 returned one row. offset=1 with limit=1 and skip=1 with take=1 both returned empty, despite the two-row unoffset response. Forward these declared inputs without promising reliable page-two semantics or treating empty as the end.

Status routes use captured sell_trx_id/market_id strings. id returned an object; ids returned an array. A two-ID status request returned two records. Unknown id returned an empty array. Bare calls also returned empty arrays and are rejected by the tools for lack of scope.

Purchase status returned {} for no id, a captured market purchase transaction ID and a zero ID. A card-market transaction is not proven to be a purchase receipt ID. The route remains catalogued but excluded until a populated contract can be captured. The zero public blockchain address returned two historical Uniswap reward rows; quantities retain their decimal strings.

Fixtures retain the first three root rows without transforming nested records. Root fingerprints describe common captured fields; heterogeneous pack-edition variants remain intact. The local response bound is 100 root rows and 256 KiB, with no partial nested group or package. Other declared filters remain unverified unless explicitly described above.
