## What the comparisons establish

- `/season` requires id: omission gave HTTP 400; the observed season id
  returned id, ends and reset_block_num.
- Default leaderboard rows and the limit=2&offset=2 rows were identical.
  The default and explicit wild sample had 20 rows; the explicit modern
  sample had 26. No paging controls are advertised for this route.
- Leaderboard-with-player returned a separate player record and 20 leaderboard
  rows. Without season, it returned an HTTP 200 error object.
- Richlist defaults to 200 rows in these captures. limit=1 returned the first
  row, and limit=2 returned the first two. Offsets 0, 2 and 4 all returned the
  same two player identities, so offset was inert in these probes. The total
  quantity changed between passes; comparisons used row identities, not
  byte equality across a live balance dataset. Only limit is advertised as
  a working observed parameter. Its minimum of one is a tool policy.
- Richlist with player retained the top rows and added player_rank. The
  separate ranking route returned rank/player/balance/token_type; its first
  call timed out and its bounded follow-up succeeded. Without player it
  returned only token_type, so the tool requires the account selector.
- Burn-event responses held 200 detailed rows versus 3344 compact rows on the
  full route. limit=2&offset=2 did not alter the full response.
- Presale returned 300 player rows, plus totals and optional curr_player.
  limit=2&offset=2 did not alter the list. A username adds the requested-player
  record. Its full response exceeded 256 KiB, but shortening only players
  permits a bounded result while retaining the other fields. This replaces
  the earlier result-bound exclusion; it does not raise the byte limit.

Fixtures retain three list rows and all surrounding fields. Result contracts
type captured common fields and check each row; optional fields seen in only
some root variants are passed through without inventing a universal contract.
An empty list is valid when the surrounding envelope still matches. Other
declared filters have not all been proven effective, and no complete-dataset
or working-offset claim is made.
